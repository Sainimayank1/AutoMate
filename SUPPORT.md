# Getting help

| You want to…                     | Go to                                                                                                     |
| -------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Ask a question or get setup help | Search existing [issues](https://github.com/Sainimayank1/AutoMate/issues), then open one if needed        |
| Report a bug                     | Open an [issue](https://github.com/Sainimayank1/AutoMate/issues/new/choose) with the bug report form      |
| Suggest a feature                | Open an [issue](https://github.com/Sainimayank1/AutoMate/issues/new/choose) with the feature request form |
| Report a security vulnerability  | **Privately**, as described in [SECURITY.md](SECURITY.md); never in a public issue                        |
| Contribute code or docs          | Read [CONTRIBUTING.md](CONTRIBUTING.md)                                                                   |

Before asking, it often helps to check the setup steps in [CONTRIBUTING.md](CONTRIBUTING.md) and
the design notes under [`docs/`](docs/).

AutoMate is maintained by volunteers in their spare time. Please be patient and kind; there is no
guaranteed response time. When you open an issue, include what you tried, what you expected, what
happened, and your environment (OS, browser, Node.js and pnpm versions), with secrets and personal
data removed from any logs.
